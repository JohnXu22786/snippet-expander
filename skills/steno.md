# Steno 短标签

Steno 会在消息发送前把 #tag 自动展开为片段库中配置的全文，无需模型额外操作。

## 规则

- 用户消息中的 #tag 已经由插件展开，直接按展开后的内容处理即可。
- 标签不区分大小写；`\#tag` 转义形式不会展开。
- 代码块（围栏或行内代码）中的 #tag 不会展开。
- 正文支持 `{{变量}}` 与 `{{变量:默认值}}` 占位符；无默认值且未提供值的占位符会保留原文。
- 片段正文可以引用其他 #标签（递归组合），插件内置循环与深度防护。

## 工具

- `steno.search`：查询片段定义、别名、所属库。展开遇到不认识的 #tag 时建议先用它查证。
- `steno.list`：浏览全部片段。
- `steno.expand`：按需展开任意文本，可附带 variables 填占位符。
- `steno.save`：把高频指令固化为片段（必须提供 tag 与 body，aliases 用于附加别名）。
- `steno.remove`：删除不再需要的片段。

## 建议

当用户多次以相近措辞提出同一类长要求时，主动用 `steno.save` 建议将其固化为短标签，并在回复中告知新标签名。
